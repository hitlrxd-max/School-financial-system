# نظام ضياء المستقبل المدرسي

الأساس البرمجي لنظام إدارة مدرسة عربية متعددة الفروع، باستخدام Neon PostgreSQL.

## الحالة الحالية

تم تنفيذ قاعدة البيانات الأساسية على Neon وتشمل:

- الأدوار والمستخدمين والفروع والسنوات الدراسية.
- الطلاب وأولياء الأمور والفصول.
- الرسوم والخصومات والمدفوعات والفواتير.
- المصروفات وتصنيفاتها.
- PostgreSQL RLS وعزل بيانات الفروع.
- Neon Auth / Better Auth.
- Buckets خاصة للمستندات والفواتير والمرفقات.
- Seed آمن يقرأ كلمة مرور المدير من Secrets ولا يحفظها في الكود.

## التشغيل

1. أنشئ Secrets باسم `DATABASE_URL` و`SEED_ADMIN_PASSWORD`.
2. شغّل migrations بالترتيب من `database/migrations`.
3. ثبّت الاعتماديات.
4. شغّل:

```bash
npm run seed
```

لا تضع كلمات المرور أو روابط قواعد البيانات أو أي مفاتيح داخل Git.

## ملاحظة

هذا المستودع يحتوي حاليًا على طبقة البيانات والـSeed الآمن. واجهة Next.js وServer Actions الخاصة بلوحة الإدارة يجب أن تُبنى فوق هذه الطبقة في المرحلة التالية، ولا توجد في هذا الالتزام أزرار وهمية تدّعي تنفيذ وظائف غير موجودة.
